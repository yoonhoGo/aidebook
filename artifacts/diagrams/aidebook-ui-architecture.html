시스템과 UI 아키텍처

현재 작업본의 Desktop·CLI·MCP 진입점, 단일 Core 소유자, 데이터 저장소와 원본 연결, 그리고 UI 화면 구조를 그렸습니다. 구현 상태가 다른 경로는 문구로 구분했습니다.

대시보드에서 상세로

오늘·다음 행동·확인 필요·진행 중·최근 완료를 Core에서 조회합니다. 항목을 열면 업무 편집 화면으로 이동하며, 할 일은 대시보드에서 바로 완료할 수 있습니다. 일정과 알림 예약은 아직 이 흐름에 포함되지 않습니다.

그래프에서 근거로

목차나 3D/목록에서 노드와 연결을 고르면 오른쪽 근거 패널을 엽니다. 저장된 근거 관계와 검색→반환→인용 예시 재생은 별도 경로이며, 예시 재생은 실제 에이전트 추적이 아닙니다.
