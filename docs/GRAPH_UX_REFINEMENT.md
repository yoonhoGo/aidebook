# 그래프 UI/UX 개선 — 2026-09-22

## 참고 자료와 적용

- [react-force-graph 공식 API](https://github.com/vasturiano/react-force-graph): 기존 react-force-graph-3d 유지. orbit controls, cameraPosition, zoomToFit 활용.
- [3D 클릭 초점 예시](https://github.com/vasturiano/3d-force-graph/blob/master/example/click-to-focus/index.html): 선택한 노드로 650ms 이동. 원점에서도 안전한 방향 계산. 모션 감소 설정에서는 즉시 이동.
- [3D 이웃 강조 예시](https://github.com/vasturiano/3d-force-graph/blob/master/example/highlight/index.html): hover/선택 주변을 밝게 하고 무관한 노드를 낮춤. 흰색 선택과 민트색 데모 이벤트를 구분.
- [Cosmograph 탐색 UX](https://next.cosmograph.app/docs/app/how-to-use/): 선택 중심 탐색과 이름·범례 제어 참고. 2D 제품의 탐색 UX 참고이며 3D 렌더러 대체는 아님.

## 구현

차분한 남색 캔버스, 자료/메모/후보/요청 범례, 가는 연결선과 작은 노드. 8개 초과 그래프는 선택·이웃·활성 노드 중심 이름 표시, 모든 이름 토글 제공. 화면 맞춤, 선택 해제, 조작 안내 및 빈 결과 안내 제공. 필터·크기 변경 시 화면 맞춤. 데모 단계는 재생 후 표시하여 평상시 공간 확보. Three.js 객체/텍스처 정리.

영구 근거 관계와 이벤트 활성화 계약은 유지한다. 선택했다고 이벤트를 생성하지 않는다. 접근 가능한 목록과 WebGL 오류 대안 유지.

## 후속 변경: 3차원 정보 지도와 Map of contents

별자리 명칭 및 원형 배치를 제거했다. 밝은 바닥 격자 위에 자료/메모/데모 요청 구역을 나누고 사선 카메라로 배치한다. 전체 보기는 노드 경계와 화면 비율을 계산해 맞춘다. 좌표는 탐색용 배치이며 의미적 유사도나 지리 위치를 나타내지 않는다.

`MapContents.tsx`는 현재 작업의 자료, 저장 메모, 후보, 요청을 접을 수 있는 목차로 제공한다. 제목/본문/유형 검색, 선택 표시, 활성 표시, 직접 연결 따라가기를 지원한다. 목차 선택 시 숨겨진 노드도 찾을 수 있도록 유형/활성 필터를 해제하고 근거 패널과 카메라를 연동한다. 좁은 컨테이너에서는 목차가 지도 위에 배치된다.

활성 노드에는 2.2초 확산 링을, 이벤트로 지정된 활성 연결에는 방향성 입자를 적용한다. 완료 상태에서도 활성 애니메이션은 유지되며 리셋하면 제거된다. 정지/재개 버튼 및 OS/앱 모션 감소를 지원한다. 정지 시 링은 정적 강조로 유지하고 입자를 제거한다. 정지는 시각 효과만 멈추며 데모 단계 진행은 계속된다. RAF, 격자, 머티리얼은 변경/언마운트 시 정리한다.

검증: 빌드 통과, 테스트 8개 통과(36개 native 메모/자료의 구역 분리·좌표 중복 검증 추가). 브라우저에서 목차 검색, 선택과 근거 패널, 연결 목록, 데모 완료, 애니메이션 정지를 확인했다. 400ms 간격 이미지 비교에서 활성 화면은 달랐고 정지 화면은 동일했다 (`artifacts/information-map/`). 해당 캡처는 마지막 카메라/라벨 조정 전의 모션 검증 자료다. 최종 화면 맞춤도 브라우저에서 확인했다. 네이티브 Tauri, 실제 에이전트 추적, 모바일 및 대규모 렌더 성능은 미검증이다.
